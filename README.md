## 📦 本地运行 (Development)

如果你想在本地研究这个高科技展示页面：

1. 克隆仓库：
   ```bash
   git clone https://github.com/your-username/HumanClaw.git
   ```
2. 进入目录：
   ```bash
   cd HumanClaw
   ```
3. 启动本地服务器（推荐使用 Python）：
   ```bash
   python -m http.server 8080
   ```
4. 在浏览器访问 `http://localhost:8080`。
